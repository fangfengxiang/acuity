# Acuity · 灵犀

**灵犀一指，洞察先机。**

A self-evolving SRE Engineering Skill for proactive risk review, evidence-driven incident response, and continuous reliability improvement.

Inspired by Google SRE, first-principles thinking, engineering control theory, and aviation-maintenance-style procedures. Independent project; not affiliated with Google or FAA.

## Capabilities
- **Before:** Design, code and release risk review, failure-mode analysis, SLO and rollback readiness.
- **During:** Evidence collection, falsifiable hypotheses, authorized mitigation and business recovery verification.
- **After:** Blameless postmortem, candidate knowledge proposals, regression evaluation and human-approved promotion.

## Safety
Production integrations start read-only. Never execute changes without explicit authorization. New knowledge stays quarantined until independently evaluated and reviewed. Do not claim real model A/B results before running them.
