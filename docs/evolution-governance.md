# Controlled self-evolution
1. Collect redacted evidence and provenance.
2. Extract failure mode, trigger, propagation, symptoms, containment, recovery and counterexamples.
3. Isolate proposals from approved rules.
4. Create positive, negative and adversarial test cases.
5. Compare baseline and candidate with fixed model, prompts and rubric.
6. Reject dangerous advice regardless of aggregate score.
7. Require human-approved PR, versioned release and rollback.

Measure risk recall, false positives, evidence quality, diagnostic efficiency, recovery verification and dangerous-action rate. Static checks are not model A/B tests. Start integrations read-only.
